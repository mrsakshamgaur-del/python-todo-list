# Python To-Do List

A simple console-based To-Do List application developed using Python. This project allows users to manage their daily tasks through an interactive menu-driven interface. Tasks are automatically saved using file handling, ensuring that they remain available even after restarting the program.

## Features

- Add new tasks
- View all saved tasks
- Delete tasks by task number
- Count total tasks
- Automatically save tasks to a text file
- Load saved tasks when the program starts
- Handle invalid menu choices

## Technologies Used

- Python 3
- Functions
- Lists
- Loops
- Conditional Statements
- File Handling

## Project Structure

```
python-todo-list/

```

## How to Run

1. Clone or download this repository.
2. Make sure Python 3 is installed on your system.
3. Open the project folder.
4. Run the following command:

```bash
python todo.py
```
